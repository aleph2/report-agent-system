## What the Writer saves

Each accepted indicator produces an immutable judgment through `save_judgment`. The task database retains assignment progress, page and image deliveries, interruptions and pointers to saved judgments. Old cases can read the three previous state families. The whole-slope tools have been removed. A launcher with an omitted workflow refuses before opening a task or starting a model. A partially migrated draft can be inspected, and previously selected historical assessments remain readable. New aggregation requires a native judgment for each scored row.

The grant and native producer binding both apply. Two separately authorized Writers can hold valid assignments for the same slope. Once the first commits a judgment, the other's save is refused. A newly proposed question and its judgment commit in the same transaction. Recovery after a successful save uses the original operation, request and assignment. It can rebuild a missing task receipt without a second judgment.

The stored submission preserves distinct uses of evidence, exact page deliveries when available, source qualifiers, competing observations, the original proposal and the effective native judgment. The scoped Reviewer view exposes the recorded authority, claim, grounds and flags. A digest binds the submission body to the judgment. Archives containing submission bodies use format v3. Existing v2 archives retain their original bytes through restore and re-export. A cold restore of the synthetic replay archive reproduced all 16 frozen Reviewer rows and their original digests, with neither the original grant database nor the task database in the fresh case. Work-in-progress task state remains part of the runtime backup.

## Review and remaining work

A refused paired save could leave a question, a narrow packet exposed a receipt identifier, the Reviewer projection could omit the effective adjustment and its supporting qualifiers, and a grant change during task finalization could misclassify an already committed judgment. The candidate includes a regression for each boundary. Human review still decides whether a rationale faithfully conveys the strength of a qualified source.

Ordinary scored judgments need confirmed source assertions and an independently reviewed interpretation of the approved criterion. The trusted host entry point `grant_judgment_inputs` binds those inputs to the confirmed plan, object and section. The synthetic importer and tests exercise this handoff. The first real report still needs its own commissioning path and actual reviewed inputs. A missing interpretation surfaces as a refusal and can be recorded as a gap.
