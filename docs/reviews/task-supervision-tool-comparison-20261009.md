## 实际暴露的问题

**材料交接遗漏，P2，阻止把 B 提升为默认审核方式。** 本次第1、2、4章在已有 tree 中共21个实质正文/表格节点。B 的三次判断输入分别包含3、10、18个。最后一次仍漏了表4-1、4-2、4-3；前面调用读过的表格不会自动进入后一次独立判断。这些表格都在当前快照内。工具和最终协调者将缺口概括为“快照之外完整正文不可用”，超出了真实证据；应区分“项目有材料但本次没传”和“项目没有材料”。原现场不变，本轮隔离结果可保留，无需为此重复启动。

**判断深度尚未证明改善。** 两条路径都正确比较了③～⑥ F值、等级及报告内界限，保留①②未计算和试算限制，与独立机械核对一致。但这仅证明内部一致性，不验证工程参数。声明（2）中“未以推测内容填充”与4.2“暂取/推定”有解释边界，B 将其列候选，不能因为更谨慎就判 B 更准确。A 也保留了1.1/1.2/1.4限定说明是否可见的候选，不能因为 A 判 satisfied 就断言其所有结论错误。

**两者均未充分展开一个可核对的潜在张力。** 3.1写流程（1）（2）“依据所提供资料完成”，其中流程（2）包括现场调查；6.1/6.2则称未开展独立现场调查。这需要解释“依据资料完成”的范围。两者保存的声明（6）理由没有展开此关系。此项是本会话读原文提出的候选，不是已确立的工程事实错误，也不能据此否定之前通过的16×7原列比较。

**范围外要求不能变成补查义务。** B 最后把渲染版式中的可见标注也列进 unchecked。最终导出是否呈现限定是合理的后续问题，但本次是正文与限定的内容检查，未授权版式执行；不应以此一项认定本次内容审核必须继续。这不消除本次确有的三张表漏传。
