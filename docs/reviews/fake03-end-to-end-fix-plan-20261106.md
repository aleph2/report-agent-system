## 2. Root cause and evidence

**F1 — both the rule and its feedback are defective.** In [writer_assessment.py](../../src/report_agent/writer_assessment.py), `_step_schema.matches_kind` rejects any nonempty rationale on a gap. Explaining why an angle cannot be calculated is useful evidence for a human reader and proposes no score. The validator text says “without a proposed score” and fails to describe this restriction. The generic tool schema also advertises fields across all three kinds. [message_fields.py](../../src/report_agent/message_fields.py) projects unregistered model-level failures to an empty field path and `value_error`. [tool_argument_feedback.py](../../src/report_agent/tool_argument_feedback.py) retains the raw error, but the model-visible root field inventory gives no kind-specific repair. First correct the contract, then the wire schema and feedback.

| Run 02 event sequence | What the record establishes |
|---|---|
| 36, 48 | Both rejected X11 evidence payloads supplied a nonempty `plausible_grades`, which the evidence branch rejects. The first also embedded explanatory prose in the numeric value. Replay these separately so a first validation failure cannot hide a second. The later accepted row was low, rank 1, value 22.5. |
| 105, 117, 129, 141 | Four X12 gap-save refusals. Every attempt had a nonempty `rationale`. The last two also omitted `question`. |
| 110, 122, 134, 146 | The next model inputs contain the public feedback: `NATIVE_TOOL_VALIDATION_ERROR`, field path `[]`, reason `value_error`. The raw native error ended with “Please fix the error and try again.” |
| Terminal receipt | `GraphRecursionError`. The per-indicator graph uses a recursion limit of 30 graph steps in [writer_indicator_steps.py](../../src/report_agent/writer_indicator_steps.py). X12 took eight model turns. Graph steps and model turns are distinct counts. |

**Engineering expectation for X12.** Use the design ratio 1:0.75 and record the survey disagreement (1:1.0). The method grades the difference between the cut-slope angle and the natural slope angle. The source omits the latter. A saved gap with that question is the expected result. A–X11’s saved low grade has source support. Its exact value of 22.5 remains subject to review because three stages do not establish three equal stage heights.

**F4 — conflict data stops at the draft (P1 for faithful delivery).** The step schema accepts `contrary_evidence`. The raw input retains it, but `_validated_judgment` does not project it to the judgment, and the tagged production code has no downstream reader for this field. A separately authored issue can record a conflict; entering the field alone gives no assurance of delivery. Reproduce offline by saving an otherwise valid outcome with a unique conflict in that field only, then inspecting the judgment or gap, issue records, Word comment and Excel row. This is a code-path finding. Run 02 never exported a report.

**F5 — repeated refused saves have no step-specific stop (P1 for finishing other work).** `IndicatorBoundary.offered` and the graph termination check track accepted saves and read attempts, but do not stop after a specified number of save refusals. The graph recursion limit eventually terminates the run. Reproduce with two distinct invalid saves for one indicator; assert a typed interruption, both refusal reasons, preservation of earlier rows, and availability of independent work. Also reproduce the P2 late-issue case: a conflict first visible on the third read currently loses the issue tool exactly when it is needed.

[fake_verification.py](../../src/report_agent/fake_verification.py) invokes `run_mini_assessment`, which allows exactly A and B and records Writer outcomes. The normal Coordinator-led entry is `run_report` in [deep_runtime.py](../../src/report_agent/deep_runtime.py). It identified a missing structured rank field in the older compact Writer interface. It did not establish that the Coordinator refactor caused the observed X12 failure.

The runner imported the guard from the package module, which has a different context variable and class identity. The guard correctly refused the unmatched identity.
