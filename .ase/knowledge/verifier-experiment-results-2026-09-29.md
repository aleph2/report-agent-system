## What this rules out, and what remains unproved

- Actual system/input audits rule out stale role text for these evaluated runs.
  Model response metadata identifiesdeepseek-v4.1-flash. Native non-message HTTP
  parameters are grounded in frozen code/configuration, not falsely called a capture.
- Sources and original results remained intact. Revisions were in isolated forks;
  no knowledge graph migration, legacy application modification or manual insertion
  of defect answers into the native agent took place.
- Some decisive evidence arrived in failed runs; retrieval absence cannot explain
  every failure. Task027 nevertheless missed a decisive page, so that particular
  run must not be described as repeated failed interpretation of the same page.
- The compact view exactly preserves extracted rows and geometry, and some same-page
  messages shrink. It adds explicit structural relationships, so it is not a pure
  length experiment. Neither size reduction nor large context proves a causal
  attention or provider-truncation explanation.
- An agent can recognize a factual mismatch yet fail to reflect it in acceptance,
  miss a mismatch after seeing its source, or never select the source. These public
  observations support separate diagnostic questions; hidden reasoning is neither
  inspected nor needed to label the observable outcome.
