## Proposed minimal representation

Retain every table's existing extracted rows byte-for-byte as values: row/column
order, strings, empty strings and nulls. Retain page/source/hash/locator metadata,
candidate-table order, extraction limits and table/page bounding boxes. Retain the
same PDF library, extraction settings and verified original-file access.

For a compatible rectangular grid, obtain complete cell rectangles from the
extractor (including empty cells), encode unique x/y edges once, and express each
cell as1-based [row,column,row_span,column_span]. Its exact original bounding box
is reconstructible from the edge arrays; no floating-point coordinate rounding,
semantic header filling, value/unit inference or neighbor-based merge guessing.
Check that grid dimensions/anchors agree with the existing extracted row matrix.
If alignment is ambiguous, preserve the raw table representation and state the
fallback rather than inventing spans. Empty/drawing-frame candidates remain.

The old raw view exposed only nonempty-cell bounds. Complete empty-cell geometry
and explicit spans add visible structural relationships, even though they are
mechanically derived from the same PDF. Declare this as compact geometry plus
structure made explicit, not a pure character-count reduction. Any quality change
cannot be uniquely attributed to shorter text. Build raw output first, convert
per table, and retain raw on invalid anchors, overlaps or uncertain coverage so a
conversion failure cannot discard another table or frozen text. Grid column numbers
are geometric positions, never assertions about printed column labels.

Only the normal read_source_page/search_sources table supplement uses the selected
compact representation. Existing inspect_source_page continues to offer raw table
geometry for the same original page; include a clear raw-access locator in compact
observations. No new tool/parameter or permission is added to the agent catalog.
Read-only tools remain read-only and project/source ownership checks remain intact.

Select this through an optional fresh-fork experiment flag, requiring the existing
calibrated artifact/grounded setting for this comparison. Bind the flag to target
identity and forbid switch/removal on resume. Defaults and previous configuration
records remain unchanged. No new OCR/index/cache, graph use or legacy code reuse.
