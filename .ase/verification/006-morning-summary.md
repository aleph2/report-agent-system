## 修复了什么

- 草稿与审核使用各自的提交参数，不再要求作者填写审核专用字段。
- 智能体观察中区分内部提交记录与真实成果，避免把任务编号当草稿编号。
- 明确的修订前版关系、审核目标关系由程序保存，不要求模型在多个字段重复抄写同一个编号。仍保留权限、目标存在及实际读取检查。
- 连接、超时、权限、限流错误有安全的明确分类；没有新增一套 HTTP 重试器。
- Markdown 表格通过现有解析库导出为 Word 表格；页面下载结果含九个表格、准确版本号及非工程批准声明。完整格式标准的排版合规性仍未验收。

## 必须保留的限制

- 评分体系、权重及风险等级需要项目负责人确认。草稿三处保留了待确认声明，但“总体可靠／可作为依据”等局部措辞仍不完全一致。
- 模型审核曾出现明显算术表述错误，不能据其“复算无误”断言证明工程数值正确。资料中的里程、坡高等分歧仍需核对原件和人工处理；不把模型选择较不利值当作用户已经裁决。
- Graph 动态修订后的生产者影响重评估、新增事实相关性判断尚未完整实现。当前能识别版本变化或检索失败，不自动宣称下游已更新正确。
- 真实运行记录 143 次模型请求回调、141 次成功响应；包含修复前错误、恢复及一次取消。合成 graph 场景 82 次请求／响应。框架接入及能力路径已证明，**调用效率提升没有证明**。SDK 内部重试和缺失用量不能按这些次数直接推算账单。
