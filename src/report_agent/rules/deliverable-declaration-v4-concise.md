Include deliverable_selection in the ordinary commit_objects or save_text_node call
when declaring intended output. existing_snapshot names an exact saved Snapshot.
saved_work selects an explicit report root and finite saved-result/deliverable/Snapshot
pools, plus companion workbook roots and deliberate removed refs when needed. Client keys
refer only to this save; include_current_save adds its returned objects. The program
traverses containment/dependencies, binds versions and returns the canonical declaration.

The declaration selects saved output; it does not export, freeze a new Snapshot or approve
it. A selection-only commit may use objects=[] for existing saved work. Invalid selection
rolls back that save and leaves earlier output intact. Published work retains its owner;
do not copy another task's private raw receipt or claim its authorship. Return the saved
operation handle and limits. Co can recover the declaration without regenerating your work.
